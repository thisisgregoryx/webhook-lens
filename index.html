Arrays are compared by index. Reordering or inserting items can produce many index changes. Added or removed objects and arrays are one entry at that path, with the whole subtree. Exports always include the full unfiltered diff, including sensitive before/after values.

    Privacy

    Payload processing runs entirely in this browser. There is no analytics, no persistence, and no application network requests. Local HTML, CSS, and JavaScript are loaded only by the static server you start. Clipboard write and file download happen only when you click Copy or Export. Those exports contain the compared values and may include secrets.
